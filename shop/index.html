Starter kits

a set of models and the code to place them

Install once, then one line per model.

Models are plain three.js objects. Each category downloads only the first time you create something from it.

  1. Installnpm install three-premade three, or load both from a CDN with an import map.
  2. CreateCall createObject with a type and variant, plus any colours you want.
  3. AnimatecreateAnimator gives you play, stop and setSpeed for the model's built-in clips.

CC0

            
Every model is public domain (CC0 1.0): use it in anything, commercial included, no attribution needed. The library code is MIT. Every model is original and built by the three-premade project, no scanned or third-party assets.

          

          

            
Recolour anythingPaint, trim, fabric and wood colours are options, not textures.

            
AnimatedDoors, wheels, lights, walk cycles. Run several clips at once.

            
Export to .glbDownload any configured model as a binary glTF from the browser.

            
Small by defaultProcedural models are code, not files. Categories load on demand.

            
Thousands of versionsEach model has variants and trims, all one option away.

            
three.js r160 and upNo framework lock-in and no build step required.
