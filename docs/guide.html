Using three-premade in code

Every model is a regular three.js Object3D. This page covers installing the package, creating and configuring models, playing their animations, and keeping big scenes fast.

Install

With npm (or pnpm, yarn, bun):

npm install three-premade three

three is a peer dependency: if your project already has three.js, that copy is reused. three-premade needs three 0.160 or newer.

Without a bundler

Load both from a CDN with an import map. three/addons/ is needed too, because HD models use the GLTF and Draco loaders and exports use the GLTF exporter.

<script type="importmap">
{ "imports": {
  "three": "https://cdn.jsdelivr.net/npm/three@0.170.0/build/three.module.js",
  "three/addons/": "https://cdn.jsdelivr.net/npm/three@0.170.0/examples/jsm/",
  "three-premade": "https://cdn.jsdelivr.net/npm/three-premade@0.1/src/index.js"
} }
</script>
<script type="module" src="main.js"></script>
ES modules need a web server. Opening an HTML file straight from disk won't load modules. Use any static server, for example npx serve or npm run serve inside the package.

Quick start

A complete scene: renderer, camera, light, one model and a render loop that drives its animations.

import * as THREE from 'three';
import { createObject, createAnimator } from 'three-premade';

const renderer = new THREE.WebGLRenderer({ antialias: true });
renderer.setSize(innerWidth, innerHeight);
renderer.shadowMap.enabled = true;
document.body.appendChild(renderer.domElement);

const scene = new THREE.Scene();
scene.background = new THREE.Color('#e9ebf1');
scene.add(new THREE.HemisphereLight(0xffffff, 0x8899aa, 2));

const camera = new THREE.PerspectiveCamera(40, innerWidth / innerHeight, 0.1, 200);
camera.position.set(6, 3, 7);
camera.lookAt(0, 0.8, 0);

const car = await createObject('car', { variant: 'suv', color: '#b3261e' });
scene.add(car);

const anim = createAnimator(car);
anim.play('lights');

const clock = new THREE.Clock();
renderer.setAnimationLoop(() => {
  anim.update(clock.getDelta());
  renderer.render(scene, camera);
});

Models are measured in metres, sit on the ground at y = 0 and cast and receive shadows by default.

Creating objects

createObject returns a Promise<THREE.Object3D>. These four calls do the same thing, so use whichever reads best in your code:

createObject('car', { variant: 'minivan', color: 'blue' });
createObject('car:minivan', { color: 'blue' });
createObject({ type: 'car', variant: 'minivan', color: 'blue' });
createObject({ Car: 'minivan', Color: 'blue' });

The returned object carries object.animations (standard THREE.AnimationClips) and object.userData.premade with the type, variant, options and animation names.

Options every model accepts

OptionWhat it does
variantWhich version, e.g. 'minivan'. Defaults to the first one.
colorMain colour: a CSS name, '#ff0000' or 0xff0000.
scaleUniform scale multiplier.
position[x, y, z]
rotationY rotation in radians, or [x, y, z].
castShadow, receiveShadowBoth true by default.
seedA different random variation for models that have one (books, trees, outfits).

An unknown type or variant throws an error that lists the valid names.

Variants and versions

Each type has variants (sedan, suv, minivan) and many variants have versions, called trims in code (sport, luxury, offroad). Ask for a version by joining the names with a dash, or pass the trim option:

const a = await createObject('car', { variant: 'sedan-sport' });
const b = await createObject('car', { variant: 'sedan', trim: 'sport' }); // same model

const nurse = await createObject('person', { variant: 'nurse', trim: 'winter' });

To list them, use the catalog helpers:

import { CATALOG, trimsOf, expandVariants, resolveVariant } from 'three-premade';

CATALOG.car.variants;                    // ['sedan', 'hatchback', 'wagon', …]
trimsOf(CATALOG.car, 'sedan');           // ['sport', 'luxury', 'offroad', …]
expandVariants(CATALOG.car);             // every full name: 'sedan', 'sedan-sport', …
resolveVariant(CATALOG.car, 'sedan-sport'); // { variant: 'sedan', trim: 'sport' }

Colours and options per type

On top of color, many types have extra colour keys and settings. CATALOG[type].options describes them, and the model browser shows only the colour rows that change the selected model.

const car = await createObject('car', {
  variant: 'coupe',
  color: '#24477a',       // body paint
  interiorColor: '#7a6a58',
  rimColor: '#1d1c1a',
  metallic: 0.8,
  plate: 'PREMADE',
});

const bus = await createObject('bus', { variant: 'double', accentColor: '#f2c200', roofColor: 'white' });

console.log(CATALOG.sofa.options); // { color: 'upholstery', accentColor: 'pillows', wood: 'legs/frame' }

People take options such as skinTone, hairStyle, shirtColor, hat, glasses and height. Anything you don't set is picked from seed.

Animations

createAnimator(object) controls the animations of one object. Call update(delta) every frame.

import { createAnimator } from 'three-premade';

const anim = createAnimator(car);
anim.names;                 // every animation this object has
anim.play('drive');         // several can run at once
anim.play('hazards');
anim.toggle('lights');      // returns true when it's now playing
anim.stop('drive');         // eases back to rest
anim.stop();                // stop everything
anim.setSpeed(0.25);        // slow motion for everything
anim.setSpeed('drive', 2);  // or one animation
anim.playing;               // names playing right now
anim.isOneShot('steerLeft'); // true

// in your render loop
anim.update(clock.getDelta());
  • One-shot animations such as steerLeft, steerRight and gearUp play once and hold their pose.
  • Exclusive groups replace each other: drive and reverse, or steerLeft and steerRight, or hazards and the indicators. Pass { exclusive: true } to play to stop everything else.
  • play(name, { loop, fade, speed }) takes optional settings. fade is the cross-fade in seconds.

Cars have drive, reverse, steer, steerLeft, steerRight, hazards, leftSignal, rightSignal, lights, brake, idle, doors, windows, bonnet, boot and wipers. People have walk, run, idle, wave, sit, dance and more. Each animator controls only its own object, so one car can drive while another waits with its hazards on.

The clips are ordinary AnimationClips, so your own THREE.AnimationMixer works too.

Lights on vehicles

Vehicles come with real spotlights for headlights. The lights animation switches them on, and brake, the indicators and hazards light their lamps.

const taxi = await createObject('car', { variant: 'taxi' });
createAnimator(taxi).play('lights');

// in a big scene, skip the spotlights; the lamp glow stays
const parked = await createObject('car', { variant: 'sedan', lights: false });

Every spotlight costs GPU time, so pass lights: false to all but a few hero vehicles.

Tree-shaking and category imports

Each category is its own module, loaded with a dynamic import() the first time you create something from it. Vite, webpack and Rollup split these into separate chunks automatically, and "sideEffects": false lets them drop anything unused.

If you prefer static imports, import a category's factory directly. These calls are synchronous:

import { createCar } from 'three-premade/vehicles';
import { createPerson } from 'three-premade/people';

const suv = createCar({ variant: 'suv' });
const crowd = Array.from({ length: 20 }, (_, i) => createPerson({ seed: i, detail: 'low' }));

Entry points:

    three-premade/vehicles re-exports cars, heavy and transport. Utilities live at three-premade/catalog, /animation, /stage and /export.

    Preload

    Fetch the code (or .glb) for some types ahead of time, for example behind a loading screen, so later createObject calls resolve without a network wait:

    import { preload } from 'three-premade';

await preload('car', 'bus', 'hd-sofa:leather-cognac');

    The catalog API

    The catalog describes every model without loading any model code, so it is cheap to import for menus and search.

    import { CATALOG, CATEGORIES, listModels, expandVariants } from 'three-premade';
// or: import { CATALOG } from 'three-premade/catalog';

CATEGORIES;                // ['vehicles', 'furniture', …]
CATALOG.car.label;         // 'Car'
CATALOG.car.category;      // 'vehicles'
CATALOG.car.options;       // option names and what they do
expandVariants(CATALOG.car).length;

const all = listModels();  // one entry per model, versions included
// { type, variant, base, trim, category, sub, source, quality, label }
const hd = all.filter((m) => m.quality === 'hd');

    Export to GLB

    Export any configured model, animations included. The exporter is only loaded when you call it.

    import { downloadGLB, exportGLB } from 'three-premade/export';

await downloadGLB(car, 'my-car.glb');   // browser download
const bytes = await exportGLB(car);     // ArrayBuffer, e.g. to upload

    The stage helper

    For demos and prototypes, createStage sets up a renderer, camera, orbit controls, soft lighting, a shadow-catching ground and a render loop that drives animations.

    import { createObject } from 'three-premade';
import { createStage } from 'three-premade/stage';

const stage = await createStage(document.body, { background: '#e9ebf1' });
const bus = await createObject('bus', { variant: 'double' });
const anim = stage.add(bus, { play: ['drive', 'lights'] }); // returns the animator
stage.frame(bus);

// stage.scene, stage.camera, stage.renderer and stage.controls are yours to use
// stage.dispose() removes everything

    Options: background (a colour), ground, shadows and controls; the last three default to true.

    HD Blender models

    Types that start with hd- are higher-detail models made in Blender and shipped as Draco-compressed .glb files inside the package (hd/models/). They load through the same createObject.

    const sofa = await createObject('hd-sofa', { variant: 'leather-cognac', color: '#6b3a1e' });
scene.add(sofa);

    By default they're fetched from jsDelivr's copy of the package, so they work with no bundler setup. To self-host, copy node_modules/three-premade/hd/models/ into your public folder and point the loader at it. You can also serve the Draco decoder yourself:

    import { setModelBaseUrl, setDracoDecoderPath } from 'three-premade';

setModelBaseUrl('/assets/three-premade/hd/models/');
setDracoDecoderPath('/draco/'); // default: the decoder on gstatic

    On HD models, color recolours materials named paint or primary, and secondaryColor recolours secondary or fabric materials.

    Performance tips

    • Turn off spotlights: pass lights: false to vehicles that don't need real headlights.
    • Low-detail people: detail: 'low' drops a person from about 30 to 40 thousand triangles to 5 to 8 thousand, which suits crowds.
    • Instance repeats: for many copies of one static model (trees, cones, bollards), build it once and draw its meshes with THREE.InstancedMesh, reusing each mesh's geometry and material.
    • Share, don't rebuild: object.clone() reuses geometry and materials. Call createObject again only when the copy needs its own colours.
    • Shadows: set castShadow: false on small or distant props, and keep shadow map sizes modest.
    • Preload the categories you need while showing a loading screen.

    FAQ

    Can I use the models in a commercial project?

    Yes. Every model is CC0 1.0 (public domain): use, change and sell it in anything, no attribution needed. The library code itself is MIT. Every model is an original work of the project, built in code. Each object also reports userData.premade.license === 'CC0-1.0'.

    Does it work with React Three Fiber?

    Yes. Create the object once (for example in useMemo with a suspense-friendly loader, or in an effect) and render it with <primitive object={model} />. Call the animator's update from useFrame.

    Why does createObject return a promise?

    Each category's code is downloaded on first use, and HD models are files. Category imports such as three-premade/vehicles give you synchronous factories if you'd rather load up front.

    Which way do models face, and how big are they?

    Sizes are in metres and models sit on the ground at y = 0. Use rotation to turn them.

    An HD model fails to load. What should I check?

    Check that the file exists at your setModelBaseUrl location as <type>/<variant>.glb, that three/addons/ is in your import map, and that the Draco decoder path is reachable.

    How do I find the name of a model?

    Open the model browser, pick a model and copy its code, or search listModels().
